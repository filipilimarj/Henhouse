Descrição do Projeto

Este aplicativo foi desenvolvido sem fins lucrativos, exclusivamente como uma ferramenta de apoio e entretenimento para utilização em um servidor de GTA RP (Grand Theft Auto Roleplay).

O projeto não possui finalidade comercial e não tem como objetivo gerar lucro, vender serviços ou oferecer qualquer vantagem financeira dentro ou fora do jogo. Sua finalidade é proporcionar uma experiência complementar aos jogadores, facilitando determinadas funcionalidades e tornando a experiência de roleplay mais organizada e interativa.

Este projeto é independente e não possui vínculo oficial com a Rockstar Games ou com a franquia Grand Theft Auto.

Uso: exclusivamente para fins recreativos e de roleplay em GTA RP. Finalidade: projeto pessoal/comunitário e sem fins lucrativos.
